# Unit-1-Project-1---Listicle-Part-1

A small Express-based listicle web app that showcases local music venues in a clean, card-based layout using HTML, CSS, and vanilla JavaScript with PicoCSS styling.

## Features

- Responsive homepage with a list of live music venues
- Five-plus unique list items, each with shared attributes
- Individual detail pages for each venue
- Custom 404 page for missing routes
- Static assets served by Express
- Simple backend API for the list data

## Tech Stack

- Node.js
- Express
- Vanilla HTML, CSS, and JavaScript
- PicoCSS

## Run locally

1. Install dependencies:
   npm install
2. Start the server:
   npm start
3. Open the app in your browser:
   http://localhost:3000

## Project structure

- `server.js` – Express server and route handlers
- `public/index.html` – Homepage markup
- `public/app.js` – Frontend list rendering logic
- `public/styles.css` – Styling and layout
